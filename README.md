# Supply Chain & Logistics Performance Analysis

## Project Overview
An end-to-end data analytics project focused on analysing supply chain operations, sales performance, and shipping efficiency across different markets and regions.

The project uses Python for data cleaning, PostgreSQL for SQL-based analysis, and Google Data Studio for interactive dashboard development.

## Tools & Technologies
- Python
- Pandas and NumPy
- PostgreSQL
- SQL
- Google Data Studio
- Jupyter Notebook
- Visualisation and Business Intelligence

## Project Objectives
- Analyse overall sales and order performance.
- Identify shipping delays across different shipping modes.
- Compare delivery performance across geographical regions.
- Identify top-performing product categories.
- Evaluate market-wise sales performance.
- Build an interactive dashboard for business insights.

## Key Analysis

- Shipping performance across different shipping modes.
